# NEBULA — Next-Gen Ticket Booking Platform 🎟️🚀

**NEBULA** is a futuristic ticket-booking website designed to make discovering and booking events feel seamless, immersive, and exciting. Featuring a sleek dark UI, neon accents, interactive seat selection, and a streamlined checkout experience, NEBULA reimagines how users explore concerts, movies, and live events.

### ✨ Features
- 🎨 **Futuristic UI/UX** — Modern dark theme with neon gradients and smooth animations.
- 🔍 **Smart Event Discovery** — Search, filter, and sort events by category and city.
- 💺 **Interactive Seat Selection** — Explore seating options and select preferred seats.
- 🎫 **Ticket Tiers** — Compare ticket options and pricing.
- ⚡ **Streamlined Checkout** — Review bookings and experience a simple checkout flow.
- 📱 **Responsive Design** — Designed for a smooth experience across different screen sizes.
- ❤️ **Favorites & Ticket Wallet** — Save events and view demo booking confirmations.

### 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript

### 🚀 Getting Started
1. Clone this repository.
2. Open `index.html` in your browser, or run a local development server.
3. Explore events, select seats, and test the demo booking flow.

### ⚠️ Project Status
NEBULA is currently a **front-end prototype**. Payments, authentication, live seat availability, and booking management are simulated and require backend integration for production use.
